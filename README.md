# 立ち絵*LINK 更新情報

このリポジトリは、公開済みの **立ち絵*LINK（TachieLINK）** の更新情報を、アプリから参照できる静的JSONとして提供します。

## 公開データ

- `tachielink/v1/beta.json`：公開済みβ版の更新情報
- `v1` はJSON形式の仕様バージョンです。アプリ本体のバージョンではありません。

公開するのはバージョン番号とリリース概要のみです。配布ZIP、購入者情報、Discord ID、ルームURL、アプリの設定・画像・ログは配置しません。

アプリ本体の入手・更新はBOOTHの購入済み商品一覧から行ってください。

このリポジトリは更新情報の配信専用です。公開済みの頒布情報を確認したうえで、必要なJSONだけを更新します。
